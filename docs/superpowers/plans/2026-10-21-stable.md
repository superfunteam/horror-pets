# Stable: build plan

**Spec:** `docs/superpowers/specs/2026-10-21-stable-design.md`. Executed natively, test-first for the game logic.
Branch `stable`, on top of `home-hud`.

## Tasks

1. **Model and save** (`model/Model.kt`, `data/SaveCodec.kt`; tests in `SaveCodecTest`)
   - `GameState(version = 2, pets = emptyMap())`; `unlocked(id)`, `unlockedCount`.
   - Decode: version < 2 → `GameState()`; pets only as saved (no auto-add); `selected` must be in pets.
2. **View model** (`ui/GameViewModel.kt`, `ui/Screen.kt`; tests in `GameViewModelTest`)
   - `Screen.Title` after loading, always; `onStart()` → starter pick (`Switcher(ONBOARD)`) or Home (+ the toast
     computed at load).
   - Starter pick creates the stable with that one killer.
   - Win against a locked opponent (not ran) adds it at defaults → `Screen.Unlocked(pet, results)`;
     `onUnlockedDone()` → the results.
   - `UiState.stableOpen`: `openStable()` (Home, idle, 2+ killers), `closeStable()`, `onStablePick(p)`.
   - `SwitcherMode.SELECT` and `openSwitcher()` removed.
3. **Assets**: `tools/make_heads.py` → `sprites-final/<pet>/head.webp`; `tools/make_branding.py` →
   `scenes-final/title/{cover,logo}.webp`; announcer line `unlocked`.
4. **Title screen** (`ui/title/TitleScreen.kt`): art (cropped to fill), logo, PRESS START blink, OK/tap,
   Back exits. Music: the switcher track.
5. **Carousel** (`ui/switcher/SwitcherScreen.kt`): ONBOARD shows no stats and the starter subtitle; OPPONENT
   shows LOCKED tags on killers you don't have, the subtitle and an "N / 7 UNLOCKED" counter.
6. **Unlocked screen** (`ui/fight/UnlockedScreen.kt`): gold window, head medallion with light rays, "UNLOCKED!",
   "<NAME> JOINS YOUR STABLE", "N / 7 UNLOCKED", OK.
7. **Home**: stats window no longer focusable/clickable; `StableBadge` (rings, head, name, LV, XP, cycling every
   4 s, focusable from the action bar's Up, hidden while the toast shows); `StableMenu` overlay.
8. **Verify**: unit tests, lint, TV emulator at 16:9 and 4:3 (fresh start → starter → fight → unlock → badge →
   menu → switch), phone touch; commit.
